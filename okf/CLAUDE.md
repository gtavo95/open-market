# OKF bundle

This repo is **content, not code**: the source of truth for a company's products and information,
in markdown. The `wiki` module reads it by pointing at this directory; nothing to do with retrieval
or embeddings lives here.

`FORMAT.md` has the exact format of a page and why each rule exists.

## The invariant

`products/*.md` is human curation. `ingest.sh` and any automation write **only files that do not
exist**. When a source changes and the page is already there, it warns and leaves it alone.

Rewriting a curated page loses a person's work without a trace, and the reader has no way to notice
the difference between curated data and data regenerated on top of it.

## Map

```
products/      one page per product. Curated. index.md is generated by ingest.sh
company_info/  shipping, payments, whatever is not a product
ontology/      the closed vocabularies pages are curated with
governance/    the rules the agro advisor decides with, one per fact. Does not go to agro_okf/
raw/           the source PDFs. Outside git
evals/         the questions that measure whether the wiki answers well
sources.tsv    which PDF generated which page, with its hash. It does go in git
```

`./ingest.sh --help` and `./verify.sh` tell their own story better than a summary here.
